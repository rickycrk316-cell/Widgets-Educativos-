## Estructura

```
widgets/<tema>/PLAN.md          partición del caso en widgets y decisión del router
widgets/<tema>/*.html           widgets finales (generados: no editar a mano)
widgets/<tema>/<id>/            partes numeradas + manifiesto.json (aquí se edita)
kit/construir.py                ensamblador y validador (según "tipo" del manifiesto)
kit/v11/                        kit v11: head.html, script.html, validar.py, probar.js
kit/                            def_head.html, apertura_head.html, validar_definiciones.py, validar_apertura.py,
                                auditar_definiciones.py, probar_definiciones.js, renumerar.py, empaquetar_skills.py
kit/anki/                       flashcards v7: estilos.css, modelo.py, compilar_mazo.py (lint + .apkg), guia_docx.py, previsualizar.js
mazos/<tema>/                   mazos Anki: tarjetas.json (fuente), media/, .apkg y guía .docx; mazos/README.md = registro de IDs
.claude/skills/                 widget-ensenanza (v11), definiciones, apertura, flashcards, impeccable (revisión opcional)
dist/                           *.skill empaquetados de las skills propias (generados)
fuentes/                        sílabos (dos rotaciones), contratos de definiciones y apertura, protocolo de verificación, casos
docs/                           DECISIONES_v11.md (fuente de verdad), PRODUCT.md (propósito), DESIGN.md (sistema visual)
```

El kit v10 (`kit_head`, `kit_script`, `validar.py`, `probar_navegador.js`, `auditar_diseno.py`) se retiró; los 17 widgets v10 (manifiesto sin `tipo`) quedan congelados.

## Reconstruir y validar

```sh
python3 kit/construir.py                          # todos (v10 congelados se omiten, sin tocar su HTML)
python3 kit/construir.py widgets/ginecologia/menopausia_th
python3 kit/renumerar.py widgets/<tema>/<id>      # citas Vancouver por primera aparición
node kit/v11/probar.js file://$PWD/widgets/<tema>/<widget>.html /tmp/capturas          # widgets v11
node kit/probar_definiciones.js file://$PWD/widgets/<tema>/<widget>.html /tmp/capturas # definiciones y apertura
python3 kit/auditar_definiciones.py <html> <n_terminos>                                 # definiciones y apertura
python3 kit/empaquetar_skills.py                  # regenera dist/*.skill (skills propias, sin impeccable)
```

Requiere `python3` con `beautifulsoup4` (`pip install beautifulsoup4`) y `node` (`cd kit && npm ci` una vez). Las pruebas de navegador usan Playwright con el Chromium de `/opt/pw-browsers`.
